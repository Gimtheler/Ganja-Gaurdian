Strain dataset

The expanded strain library uses strain names, reported effects, flavours, terpenes, parent names, breeder names and grow attributes from the Cannabis Intelligence Database by Shannon Goddard, licensed CC BY 4.0.

The descriptions, taglines and fun facts shown on this site are original wording generated from those attributes. No source descriptions are copied. Duplicate breeder listings and non-strain product entries were removed so the library shows unique strain names.
