# Photo library

The library is split into eight folders so no folder has more than 99 image files:

- `Photos1` holds the 23 openly licensed reference photos currently used by the site.
- `Photos2` to `Photos8` are reserved for future verified strain photos.
- Each folder can hold up to 99 images.
- Name a verified strain photo by its slug, for example `og-kush.jpg` or `blue-dream-2.jpg`.
- Do not rename a photo to match a strain unless it is actually that strain.
- Keep the author, licence and source URL for every new photo and add it to `credits.html`.
- Representative photos stay labelled as representative in the interface.

The site currently uses `Photos1` only. The empty folders carry a `.gitkeep` file so GitHub keeps them in the repository.
